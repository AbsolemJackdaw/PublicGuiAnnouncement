# Public GUI Announcements [![CurseForge Project](https://img.shields.io/curseforge/dt/341727?logo=curseforge&label=CurseForge&style=flat-square&labelColor=2D2D2D&color=555555)](https://www.curseforge.com/minecraft/mc-mods/public-gui-announcement)

The Public GUI Announcements mod is a cosmetic mod that displays the GUI players are currently looking at. The mod
currently supports all vanilla GUIs and support for more screens can be added through resource pack files! You can learn
more about adding support for screens [here](https://github.com/AbsolemJackdaw/PublicGuiAnnouncement/wiki/Add-Mod-Compatibility)!
